## 2. Description

Prickcal is an open-source plugin (AGPL v3.0) that provides interactive Discord control panels for:

- Tracking in-game Trickcal progression (Apostle collection, Crayon summons, Gift codes, etc.)
- Recording and parsing Crayon summon data from user-defined message formats
